# Library import concurrency benchmark

Generated by `frames --benchmark-import /Users/prime/Movies/clips` (65 files, 10 cores, macOS Version 27.3 (Build 26C5047e)).
Each configuration ran 3 times through `LibraryManager.addFolder` with a temp cache and a temp `UserDefaults` suite.
The table shows the median wall time and the longest main-thread stall across repeats.

"Cold" means the app's library cache is empty.
One untimed warm-up pass primes the OS file cache first, so disk reads are not cold.
The stall is the longest gap between 10 ms main-thread heartbeats, minus 10 ms.

## Decision

Rule: raise the limit only if a candidate's cold-cache median is at least 20% faster than limit 2 in both modes, with no main-thread stall over 100 ms in any configuration.
Among qualifying limits, the fastest cold metadata + thumbnail median wins.

Limit 10 (one per core) met the rule, so `LibraryManager.defaultMetadataConcurrency` is `ProcessInfo.activeProcessorCount`.
