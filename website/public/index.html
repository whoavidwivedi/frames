Official macOS Distribution

How Apple Gatekeeper and Direct Distribution Work

We distribute Frames directly through our website without the Mac App Store. Here is everything you need to know about Apple requirements, Developer ID, and Gatekeeper.

Why Direct Website Distribution?

The Mac App Store enforces strict sandboxing rules that restrict direct access to hardware decoders, custom Metal shaders for external displays, and raw file system directory indexing. Direct DMG distribution gives you maximum performance without App Store restrictions.

Apple Developer ID & Notarization Standard

Apple requires macOS software distributed outside the App Store to be signed with a Developer ID Application certificate and notarized by the Apple Notary Service (`xcrun notarytool`). When notarized, Apple validates the code against malware and issues a cryptographic ticket that is stapled directly to the DMG.

xcrun notarytool submit Frames.dmg --keychain-profile "PROFILE" --wait && xcrun stapler staple Frames.dmg

First Launch on macOS (If prompted by Gatekeeper)

If opening a community preview build before official Developer ID certification, macOS Gatekeeper may display a dialog stating Apple cannot check it for malicious software. You can open it officially in two clicks:

Official Method: In Finder, go to your Applications folder, right click (or Control click) Frames.app, and select Open. In the dialog, click Open. macOS permanently remembers your approval and launches instantly thereafter.
